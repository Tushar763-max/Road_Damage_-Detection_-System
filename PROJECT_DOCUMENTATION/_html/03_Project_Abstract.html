Abstract

Road surface distress on Indian roads is still recorded largely by inspection visits and loose photograph collections. That practice is slow, and it does not attach a class label, a confidence value, or a repair trail to the picture. This project presents RoadScan AI, a web application that detects road damage from images, short videos, and live camera frames using YOLOv8.

The browser interface is built with React, TypeScript, Vite, and Tailwind CSS. The inference service is a Flask application. It loads YOLOv8_Small_RDD.pt when that file is present, otherwise best.pt, unless MODEL_PATH is set. OpenCV reads media. The model runs at image size 640. Each box is labelled with a friendly class name when the model emits a known road-damage code: longitudinal crack, transverse crack, alligator crack, pothole, white line blur, or crosswalk blur. The original class code is retained.

Severity is a visual estimate from the percentage of the frame covered by the box, with a stricter rule for potholes and a cap so that a wide crack is not automatically marked as the highest band. A risk score from 0 to 100 combines severity, confidence, and the number of boxes. Image and video analyses are stored in SQLite together with an optional latitude, longitude, and place name. The server never fills in a coordinate the client did not send. Live frames are answered and then discarded so a camera loop does not flood history.

Around the detector, the dashboard adds history, charts, a map tracker, a heatmap of coordinate buckets, a repair status trail (reported, assigned, in progress, repaired), citizen complaints, and a printable inspection report. If Flask is offline or the weight file is missing, the interface reports the failure. It does not substitute sample boxes.

The system is an MCA demonstration. Login protects the screens on that browser only. Severity is not an official pavement index, and this abstract does not claim a benchmark mAP because the repository does not store one. Video analysis skips frames and stops after 90 inferences so a CPU laptop can finish a short clip.
