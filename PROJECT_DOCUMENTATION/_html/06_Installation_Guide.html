1. Purpose

This guide installs RoadScan AI on Windows 10 for a local demonstration. The interface uses port 5173. The API uses port 5000. You need two terminals.

2. Hardware and software you need

ItemRequirement
OSWindows 10 (tested target for this project).
CPUA recent laptop CPU is enough. A GPU is optional.
RAM8 GB minimum. 16 GB is more comfortable once PyTorch loads.
DiskSeveral gigabytes for the Python environment and PyTorch, plus the .pt weight file.
Python3.12 is the version observed in this workspace. Python 3.10 or newer is the practical range for current Ultralytics builds.
Node.jsCurrent LTS with npm, so that Vite can run.
BrowserChrome or Edge.

3. Get the project folder

Copy the RoadDamageDetection folder onto the machine. The important paths are frontend, backend/app.py, backend/requirements.txt, and backend/YOLOv8_Small_RDD.pt. best.pt may sit beside it as a fallback.

4. Install and start the API

  1. Open PowerShell.
  2. Change directory to the backend folder.
  3. Create a virtual environment: python -m venv venv.
  4. Activate it: .\venv\Scripts\activate.
  5. Install dependencies: pip install -r requirements.txt. This installs Flask, Flask-CORS, Ultralytics, OpenCV, imageio-ffmpeg, and Gunicorn. Ultralytics pulls in PyTorch.
  6. Confirm the weight file is in this same folder.
  7. Start the server: python app.py.
  8. Leave this window open. The console should print Model loaded: True and the class map.
cd C:\Users\Admin\Downloads\RoadDamageDetection\backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python app.py

4.1 Check the API

Open http://localhost:5000/api/health in the browser. A healthy body looks like this shape:

{
  "status": "ok",
  "model_loaded": true,
  "model_path": "YOLOv8_Small_RDD.pt",
  "classes": ["..."]
}

If model_loaded is false, the process did not find a weight file. Copy YOLOv8_Small_RDD.pt next to app.py, or set MODEL_PATH to the full path of a .pt file, and start python app.py again.

5. Install and start the website

  1. Open a second PowerShell window.
  2. Change directory to the frontend folder.
  3. Install packages: npm install.
  4. Start the dev server: npm run dev.
  5. Open the URL Vite prints. It is normally http://localhost:5173.
cd C:\Users\Admin\Downloads\RoadDamageDetection\frontend
npm install
npm run dev

5.1 Point the website at a different API

Create frontend/.env when the API is not on port 5000:

VITE_API_BASE_URL=http://localhost:5000

Restart npm run dev after changing the file. Do not put a slash at the end.

6. First login

Register a name, email, and a password of at least six characters, or log in with student@roadscan.ai and demo123. Then follow the User Manual. Analyse one sample image under frontend/public/samples before the viva so the weights are loaded into memory.

7. Optional production-style UI build

npm run build compiles the TypeScript and writes a static site. npm run preview serves that build locally. The Flask development server is still required for detection. Gunicorn is listed for a Unix deployment and is not the Windows start command.

10. Troubleshooting

SymptomAction
python is not recognisedInstall Python and enable the “Add python.exe to PATH” option, then open a new terminal.
pip install fails on a torch wheelUpgrade pip, then retry inside the activated virtual environment. A 64-bit Python is required.
Port 5000 already in useStop the other program or set PORT to a free port and match VITE_API_BASE_URL.
Port 5173 already in useVite will offer the next port. Use the URL it prints.
CORS or failed fetchThe page must call the same origin you put in VITE_API_BASE_URL. Restart both processes after a change.
Model loaded FalseThe .pt file is missing or MODEL_PATH is wrong.
Very low confidence on every boxYou may be on the fallback best.pt. Prefer YOLOv8_Small_RDD.pt. The source comment records that best.pt scored about one percent confidence in a local test.
Video returns Failed to encodeReinstall imageio-ffmpeg inside the virtual environment.
npm install peer warningsWarnings alone are not a failure. A non-zero exit code is.

11. Stop and start next time

  1. Activate the backend virtual environment and run python app.py.
  2. In the frontend folder run npm run dev. You do not need npm install again unless package.json changed.
  3. Open the site and check the model status.

12. What not to delete

  • Do not delete the .pt files if you want detection.
  • Deleting detections.db clears history and complaints. The file is recreated empty.
  • Deleting the virtual environment only means you must run pip install again. It does not delete your source.
