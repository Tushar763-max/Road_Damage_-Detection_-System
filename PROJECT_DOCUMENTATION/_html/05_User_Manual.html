1. Who this manual is for

This manual is for a surveyor, a student demonstrator, or a faculty guide using RoadScan AI on a laptop. Installation is covered in the Installation Guide. Start here after both the website and the API are running.

2. What you can do

  • Sign in and open the dashboard.
  • Analyse a road photograph.
  • Analyse a short road video.
  • Watch a live camera and see boxes without saving every frame.
  • Review history and charts.
  • Place saved coordinates on a map and a heatmap.
  • Read a risk score.
  • Move a defect through a repair trail.
  • File a citizen complaint.
  • Print an inspection report.

3. Sign in

  1. Open the site address given in the installation guide, normally http://localhost:5173.
  2. Choose Login, or Register if you want a display name.
  3. Enter any email address you will remember, and a password of at least six characters. A demonstration pair is student@roadscan.ai and demo123.
  4. The dashboard opens. Closing the browser does not log you out. Use Logout when you share the computer.

This sign-in stays in this browser. It is a project session, not a municipal staff account. Do not use a personal password you use elsewhere.

4. How to read status

Before you trust a picture, look at the backend status. Model Online means Flask responded and a weight file is loaded. If the server is stopped, the detection pages show an error. They will not draw sample boxes and pretend they came from the model. Purple Demo marks are sample interface content. Green Model marks are Flask output.

5. Analyse a photograph

  1. Open Image Detection.
  2. Choose a JPG or PNG of a road surface. You can start with the sample images supplied with the project.
  3. Set the confidence slider if you need fewer or more boxes. A higher value keeps only the stronger boxes. The page sends 0.25 unless you change it.
  4. Optionally type an area name. Use the location control if you want a real GPS point stored. Leave it empty if you do not have one.
  5. Start the analysis and wait. The first call can be slower while the model is warm.
  6. Read each box: class name, confidence, and severity colour.
  7. The run is stored. Open Detection History to see it again.

5.1 How to explain severity

Severity looks at how much of the picture the box covers. Small boxes are low. Larger boxes are medium or high. Potholes are treated more strictly than cracks. Say clearly that this is a visual estimate for sorting, not a measured depth.

6. Analyse a video

  1. Open Video Detection.
  2. Choose a short clip, about 5 to 15 seconds. A long video is sampled and will still stop after 90 analysed frames.
  3. Add an optional place or GPS point for the clip as a whole. The system stores one location for the file, not a point per frame.
  4. Start the analysis. CPU inference can take a few minutes.
  5. Play the annotated video in the page. If it does not play, use the download path from history and check that FFmpeg was installed with the Python packages.

7. Live camera

  1. Open Live Camera and allow the browser to use the camera.
  2. Point the camera at a road surface with reasonable light.
  3. Boxes update from individual frames. These frames are not written into Detection History.
  4. If you need a permanent record, take a still image on the Image Detection page or file a complaint with a photo.

8. History, analytics, and the printed report

Detection History lists image and video runs, newest first. You can open one record or delete it. Analytics & Reports charts the stored set. From a record, open the inspection report. Allow pop-up windows if the browser asks. Use the browser print command to save a PDF or to print. The report shows file name, risk score, repair status, GPS when it exists, and a table of boxes.

9. Map and heatmap

Live Tracker shows only records that have both a latitude and a longitude. A complaint or detection without GPS will not appear, even if it has an area name. Damage Heatmap groups nearby points. A busier or more severe group is drawn as a higher zone. If nobody has stored coordinates yet, the map is empty on purpose.

10. Risk score

Open Risk Score to read the 0–100 value. Higher means more boxes, higher severity, or higher confidence. Bands are low below 40, medium from 40 to 69, and high from 70 to 100. Use the score to order a work list, then confirm the site in person.

11. Road repairs

  1. Open Road Repairs.
  2. Select a detection or a complaint.
  3. Set the status to Assigned when a crew is named, In Progress when work has started, and Repaired when the site is closed.
  4. Add a short note. The note is kept in the status history with the time.

12. Citizen report

  1. Open Citizen Report.
  2. Enter the area name. This is required.
  3. Describe the problem in at least eight characters.
  4. Attach a photo if you have one. When the model is running, the photo is analysed and the boxes are stored on the complaint.
  5. Submit. The complaint starts as Reported.
  6. You can filter the complaint list by the email address stored with the report.

13. Settings and About

Settings holds the local profile. About shows the project abstract, the problem statement, and the team block: Tushar Ravidas Jarwal, Roll No. 19, guided by Professor Ajay Patil.

14. Common situations

What you seeWhat to do
Backend unavailableStart the Flask server. See the Installation Guide.
API is up and the model is missingPlace YOLOv8_Small_RDD.pt next to app.py and restart Flask.
No boxes on a road that clearly has damageLower the confidence and try a closer, sharper photograph. The model can still miss a class it was not trained to see.
Video is slowUse a shorter clip. The server already skips frames.
Video file will not playConfirm imageio-ffmpeg installed. The mp4v fallback is less reliable in Chrome.
Map is emptyRun a detection again and supply a real GPS point.
Popup did not openAllow pop-ups for the site, then open the report again.
Logged out after someone cleared site dataSign in again. History on the server is still there.

15. Good practice while demonstrating

  • Show /api/health before the first image so the audience sees model_loaded true.
  • Say the severity sentence from section 5.1.
  • Show one failure: stop the server, attempt an upload, restart, and show recovery.
  • Do not describe the login as a secure government login.
